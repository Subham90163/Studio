# Studio Management System - Frontend

This is the React frontend for the Studio Management System with a minimal cinematic aesthetic, subtle parallax scrolling, and glassmorphic UI.

## Tech Stack
- React 18
- Vite
- Tailwind CSS v3
- React Router v6
- Axios
- Lucide React

## Setup & Running

1. Open a terminal in this directory:
   ```bash
   cd "C:\Users\Subham Tiwari\Desktop\Studio management system\frontend"
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```
   *(On Windows PowerShell with execution policy restrictions, use `npm.cmd run dev`)*

3. Open `http://localhost:5173` in your browser.

## Default Credentials (After Backend Seed)
- **Admin**: `admin@studio.com` / `admin123`
